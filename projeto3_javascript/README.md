# Tema

- Nome do projeto: projeto3_javascript;
- Nome da página: Descubra seu caminho no Front-End;

## Divisão de tarefas

- Utilizei o chatGPT para criar a base de HTML e CSS, também utilizei como correção dos comandos feitos no JavaScript;

## Comandos Javascript utilizados

- .classList.toggle() - utilizado para alternar entre o tema claro e escuro na página;
- .textContent - utilizado para adicionar texto dentro de um elemento;
- .preventDefault() - cancela a ação padrão que o navegador executaria quando um determinado evento ocorre;
- .style.display = "none" - o elemento deixa de ser visível e não ocupa mais espaço no layout;

## Funcionamento

- A página possui um botão para alternar, a página, entre o tema claro e escuro;
- Possui um campo, onde pode ser preenchido com o nome, e um seletor de programação;
- Ao preencher o nome, escolher uma programação e clicar no botão "Gerar orientação", aparecerá uma mensagem na parte da orientação, mostrando o que deve ser estudado;
